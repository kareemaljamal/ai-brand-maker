# BrandMaker AI

## التوليد المباشر

مسار إنشاء المشروع يطلب 6 أسماء جديدة من Gemini عند كل طلب. لا يستخدم أسماء محلية عند غياب المفتاح أو فشل الخدمة، ولا يكمل الرد الناقص بأسماء جاهزة. عند تجديد الأسماء تُرسل الأسماء السابقة للنموذج وتُرفض النتائج المكررة.

تظهر الأسماء أولاً، ثم تُطلب الهوية والتسعير والتسويق والتوجيه البصري. القسم الذي يفشل يظهر بحالة خطأ، ولا يُعرض بديل جاهز باعتباره نتيجة ذكاء اصطناعي. الصور لها مسار مستقل لم يتغير في هذا الإصلاح.

## Google AI Studio وحسابات المستخدمين

فحص النسخة المنشورة في `https://brandmaker-ai.ai.studio/` يوم 21 أكتوبر 2026 أظهر أن `POST /api/brand/generate-names` يرجع `404 Cannot POST /api/brand/generate-names`، رغم أن `/api/status` يقول إن المفتاح موجود. ملف `server.js` القديم في المستودع لا يحتوي على هذا المسار، بينما `server.ts` يحتوي عليه. هذا يرجّح نشر ملف سيرفر قديم مع واجهة أحدث. يجب إعادة بناء ونشر الواجهة والسيرفر معاً باستخدام `npm run build`، واختبار المسار في النسخة المنشورة بعد النشر.

يجب أن تكون النسخة التي تعمل بالفعل محدثة بهذه الملفات. تعديل نسخة GitHub أو النسخة المحلية لا يعني أن التطبيق المشترك في AI Studio تحدّث تلقائياً.

إذا فشل الطلب، تعرض الواجهة رسالة توضح غياب `GEMINI_API_KEY` أو رفض الوصول أو انتهاء الحصة أو عدم توفر النموذج. وجود المفتاح وحده لا يثبت نجاح الاتصال. راجع إعدادات الأسرار والمشروع المرتبط بالمفتاح في النسخة التي تشغّل التطبيق. لا تضع المفتاح في كود الواجهة أو GitHub.

لا يمكن تحديد سبب فشل حساب معين من المستودع وحده؛ يلزم تجربة الرابط المشترك وقراءة رسالة الخطأ الناتجة. راجع [دليل Google AI Studio الرسمي](https://ai.google.dev/gemini-api/docs/aistudio-build-mode).

## التشغيل المحلي

استخدم Node.js 24، ثم:

```sh
npm ci
```

انسخ `.env.example` إلى `.env` وضع مفتاح Gemini الخاص بالمشروع في `GEMINI_API_KEY`. يمكن تحديد نموذج متاح للمشروع عبر `GEMINI_TEXT_MODEL`، ثم شغّل:

```sh
npm run dev
```

افتح `http://localhost:3000`. عند الاستضافة يجب تشغيل سيرفر التطبيق، وليس ملفات الواجهة وحدها.

## التحقق

```sh
npm test
npm run lint
npm run build
```

اختبارات التكامل تستخدم خدمة Gemini محاكاة وتغطي الطلبات المتكررة، غياب المفتاح، رفض الوصول، انتهاء الحصة، تعطل الخدمة، الرد غير الصالح، الأسماء الناقصة والمكررة. لا تستهلك الاختبارات حصة Gemini، ولا تُثبت نجاح الاتصال بحساب Google الحقيقي.

أمر البناء يُحدّث `server.js` أيضاً حتى لا تبقى النسخة المولّدة من السيرفر قديمة.
